List entries that are lists represent links or transclusions embedded in the item most recently processed. The resulting display is a multilevel unordered list. The input `backrefs` has an identical structure, but each fqname is a backward reference. The input `missing` is a set of fqnames that are non-existent. The input `no-read-auth` is a set of fqnames that may not be read by current user.
